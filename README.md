# FortiRule Builder

FortiRule Builder เป็นเว็บแอปภาษาไทยสำหรับสร้างคอนฟิก FortiGate CLI แบบไม่ใช้ฐานข้อมูลและไม่เชื่อมต่อ FortiGate จริง เหมาะสำหรับผู้เริ่มต้นที่ต้องการร่างคอนฟิก VLAN, DHCP และนโยบาย Firewall จากหน้าเว็บฝั่งผู้ใช้เท่านั้น

## คุณสมบัติ

- เพิ่ม VLAN ได้หลายรายการ พร้อมชื่อ VLAN, VLAN ID, พอร์ตแม่, เกตเวย์, มาสก์เครือข่าย, ช่วง IP ของ DHCP และตัวเลือกอนุญาตออกอินเทอร์เน็ต
- แสดง VLAN ทั้งหมดในตารางและลบ VLAN ได้
- สร้างนโยบาย Firewall ได้หลายรายการ โดยเลือก VLAN ต้นทาง ปลายทางเป็น VLAN ภายในหรืออินเทอร์เน็ต บริการ การกระทำ และ NAT
- NAT แบบอัตโนมัติจะเปิดเมื่อปลายทางเป็นอินเทอร์เน็ต และปิดเมื่อปลายทางเป็น VLAN ภายใน
- สร้าง FortiGate CLI สำหรับ VLAN interfaces, DHCP servers, Firewall policies และ NAT ต่อ Policy
- เพิ่มคำอธิบายภาษาไทยให้แต่ละนโยบายใน CLI ที่สร้างขึ้น
- ปุ่มคัดลอก CLI และส่งออกไฟล์ `.txt`

## การเริ่มต้นใช้งาน

```bash
npm install
npm run dev
```

เปิดเว็บที่ `http://localhost:3000`

## คำสั่งที่ใช้บ่อย

```bash
npm run lint
npm run build
```
